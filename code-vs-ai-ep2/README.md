# Code vs AI EP2 — The Radio Station

Source code for the CodeToVideo episode.

- `render_ep*.py` — renders the motion-graphics scene
- `make_sfx.py` — generates sound effects
- `make_thumb.py` — builds the YouTube thumbnail
- `assemble.sh` — final assembly (video + audio mix)

Rendered video, frames, and audio stems are not committed (build locally).
